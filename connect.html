Game Scheduler Companion

This computer opens the club's Game Scheduler, which runs on the club's main computer. Nothing is installed or stored here.

It's shown on the main computer under Settings > Club details > Other computers.

Things to check on the main computer:

  • Game Scheduler is open.
  • Settings > Club details > Other computers is ticked, and Game Scheduler has been restarted since.
  • Windows Firewall was allowed for "Node.js JavaScript Runtime" when it asked.
  • Both computers are on the same network. If the name doesn't work, try the number address shown on that Settings page.
